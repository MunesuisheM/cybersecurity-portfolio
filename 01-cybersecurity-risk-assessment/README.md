# Cybersecurity Risk Assessment & Compliance Dashboard

   ## Project Overview
   This project focuses on identifying, evaluating, and prioritizing cybersecurity risks within a fictional financial institution using the NIST Cybersecurity Framework (CSF) 2.0.

   ## Project Objectives
   - Identify cybersecurity threats and vulnerabilities.
   - Assess risks based on likelihood and impact.
   - Map security risks to NIST CSF 2.0.
   - Develop a risk register and compliance dashboard.
   - Recommend appropriate security controls.

   ## Tools and Technologies
   - Python
   - Microsoft Excel
   - NIST Cybersecurity Framework 2.0
   - GitHub

   ## Project Status
   In Progress — Initial setup and planning.

   ## Learning Outcomes
   This project will develop practical skills in cybersecurity governance, risk assessment, compliance monitoring, and security reporting.
